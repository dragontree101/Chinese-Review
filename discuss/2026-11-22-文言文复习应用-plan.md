# 初中文言文生词复习应用 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 基于 default.json（1333 条文言实词）构建 Next.js 复习应用：多规则出题（选择/填空/不知道）、多维度统计、数据在线编辑。

**Architecture:** Next.js 15.4 App Router（页面 + Route Handlers）+ better-sqlite3 单文件数据库（`data/app.db`）；出题/判定/统计逻辑放在 `src/lib` 纯函数层并被单测覆盖；页面只做展示与交互。

**Tech Stack:** Next.js 15.4、React 19、Tailwind CSS v4、TypeScript(strict)、better-sqlite3、pinyin-pro、recharts、vitest、tsx。

**Spec:** `discuss/2026-11-22-文言文复习应用-design.md`

## Global Constraints

- Next.js 必须 15.4.x；React 必须 19.x；Tailwind 必须 v4；严禁 commonjs
- TypeScript strict 模式，禁止 `any`（`unknown` + 类型收窄替代）
- 单文件 ≤ 800 行；每层目录文件数尽量 ≤ 20
- 启停/测试/调试一律通过 `scripts/*.sh`，日志写入 `logs/`（禁止直接敲 npm/python）
- 数据库文件 `data/app.db`；`data/`、`logs/`、`node_modules/`、`.next/` 加入 .gitignore
- git 提交信息末尾加 `Co-Authored-By: Claude Code <noreply@anthropic.com>`

## Review Focus

1. 同一例句出现在多条词条（同一句翻译/出处必须一致）→ 导入按 sentence 去重合并翻译；测试见 Task 2 步骤 1
2. 填空题输入空白/纯标点 → 判定返回 false 且不崩溃，可点「不知道」→ Task 3 步骤 1
3. 「错误率优先」规则在无任何作答记录时 → 返回未复习过的新词，不报错不返回空 → Task 3 步骤 1
4. 编辑 meaning 后「相同含义句子」分组与统计必须立即变化（派生不落库）→ Task 2 步骤 1 测试同字同含义分组；Task 5 验证 PATCH 后 /api/quiz 干扰项变化
5. 「判我对」覆盖后统计以覆盖后日志为准且原始作答保留 → Task 4 步骤 1

### Task 3: 出题与判定逻辑

**Files:**
- Create: `src/lib/quiz.ts`, `src/lib/pinyin.ts`
- Test: `src/lib/__tests__/quiz.test.ts`

**Interfaces:**
- Consumes: Task 2 的 `Word`、`getDb()`
- Produces:
  - `QuizRule = 'random'|'grade'|'initial'|'keyword'|'frequency'|'weakness'`
  - `pickWords(db, rule: QuizRule, value: string, count: number): Word[]`；weakness 规则：`SELECT word_id, SUM(result!='correct')*1.0/COUNT(*) AS err FROM review_logs GROUP BY word_id` 按 err 降序、`COUNT(*)=0` 的未复习词排在 err 词之后（按 id 随机）；grade 规则按 `grade=?`；initial 用 `pinyin.ts` 的 `getInitial(char): string`（pinyin-pro）过滤；keyword 对 char/meaning LIKE；frequency 按 char 出现条目数降序
  - `buildChoiceQuestion(word: Word, distractors: string[]): ChoiceQuestion`，`ChoiceQuestion { word: Word; options: string[]; answer: string }`（answer=word.meaning，options 打乱）
  - `pickDistractors(all: Word[], target: Word, n=3): string[]`（优先同 char 其他 meaning，不足从其他字随机补，去重且不含 answer）
  - `judgeFill(meaning: string, input: string): boolean`（input 去空白标点 → 与 meaning 按 `[，、；;，]` 拆词 → 命中任一关键词（包含关系）即 true；空输入/全标点 false）
