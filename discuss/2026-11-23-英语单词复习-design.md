# 英语单词复习模块 — 设计文档

日期：2026-11-23
状态：待评审

## 一、背景与目标

在现有文言文复习应用中新增**英语单词复习**模块，复用现有应用模式：随机选词 → 作答 → 统计正确率/错误率。

数据来源：[KyleBing/english-vocabulary](https://github.com/KyleBing/english-vocabulary)，以 **git submodule** 引入，第一阶段导入**初中与高中两个词库**（`full_line_jsonl/full/正序/初中.jsonl` 与 `高中.jsonl`，full 类型 = 原库完整结构，含音标/释义/例句/短语/同近义词/同根词）。

## 二、数据侦察结论（影响设计的事实）

1. **初中词库** 3223 行去重后 1991 词，**高中词库** 6008 行去重后 3753 词（词书编号分别为 `ChuZhong_2/3`、`GaoZhong_2/3`，同库两书大量重叠，重复行的释义措辞不同、例句基本一致）。
2. **初中与高中重叠 1817 词**（初中 1991 词中约九成也出现在高中词书）→ 词库按 headWord **全局去重合并**，学段取该词出现的**最低学段**：出现在初中词书的归「初中」（1991 词），仅出现在高中词书的归「高中」（1936 词），两组不重叠，合计 3927 词。
3. 词库没有更细的年级维度（无七/八/九年级信息）→ 学段就是「初中/高中」两档，另有**首字母（A-Z）**维度。
4. `trans` 字段完整性良好（初中、高中均无缺失），每条含 `pos`（词性）与 `tranCn`（中文释义）。
5. 每词含：英/美音标（`ukphone`/`usphone`）、释义列表（`trans`）、例句列表（`sentence.sentences`，英文+中文翻译）、短语列表（`phrase.phrases`）、同近义词、同根词。
6. 仓库全量约 97.5MB，submodule 采用 `--depth 1` 浅克隆控制体积。

## 三、已确认的决策（用户拍板）

| 决策点 | 结论 |
|---|---|
| 题型 | 与现有一致：**英译中选择题** + **中译英拼写题**（对应 choice/fill 两种模式） |
| 页面组织 | **独立英语板块**：`/english/review`、`/english/stats`，顶部导航加「文言文 / 英语单词」切换 |
| 管理页 | **先不做**（词库由 submodule 导入，不手动增删改） |
| 数据表 | **独立新表** `e_words` + `e_review_logs`，不与文言文表混用（字段语义差异大） |
| 词库范围 | **初中 + 高中**两库都导入，出题规则按「初中 / 高中」分档 |

## 四、方案对比

1. **复用现有 words/review_logs 表 + module 列**（否决）：char/word、单释义/释义列表字段语义冲突，所有查询和统计都要加过滤条件，脆弱且晦涩。
2. **独立表 + 独立板块**（选定）：`e_words`、`e_review_logs` 两张新表，出题/统计逻辑照 `quiz.ts`/`stats.ts` 模式另立一份，UI 组件按现有模式新写。改动面清晰，不动现有代码。
3. **现有页面内加科目切换**（否决）：/review、/stats、/manage 全部要改造成双科目，牵一发动全身。

## 五、数据库设计

```sql
CREATE TABLE e_words (
  id INTEGER PRIMARY KEY,
  word TEXT NOT NULL,              -- 单词本身（wordHead）
  level TEXT NOT NULL,             -- 学段：'初中' | '高中'（该词出现的最低学段）
  usphone TEXT,                    -- 美式音标
  ukphone TEXT,                    -- 英式音标
  meanings TEXT NOT NULL,          -- JSON 数组 [{pos, tran}]，如 [{"pos":"n","tran":"能力，才能"}]
  sentences TEXT NOT NULL,         -- JSON 数组 [{en, cn}]
  phrases TEXT NOT NULL,           -- JSON 数组 [{en, cn}]
  createdAt TEXT NOT NULL,
  updatedAt TEXT NOT NULL
);
CREATE INDEX IF NOT EXISTS idx_e_words_word ON e_words(word);
CREATE INDEX IF NOT EXISTS idx_e_words_level ON e_words(level);

CREATE TABLE e_review_logs (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  wordId INTEGER NOT NULL REFERENCES e_words(id),
  mode TEXT NOT NULL CHECK (mode IN ('choice','fill')),
  result TEXT NOT NULL CHECK (result IN ('correct','wrong','unknown')),
  userAnswer TEXT,
  overridden INTEGER NOT NULL DEFAULT 0,
  createdAt TEXT NOT NULL
);
CREATE INDEX IF NOT EXISTS idx_e_logs_word ON e_review_logs(wordId);
```

> JSON 数组存 TEXT 列是 SQLite 单库的务实选择；如需强类型约束，由 TypeScript 接口 `EnglishWord` 保证读写两端一致。

## 六、导入流程

- submodule 位置：`third_party/english-vocabulary`（浅克隆：`git submodule add --depth 1`）。
- 导入脚本：`src/scripts/import-english.ts`，读取 `full_line_jsonl/full/正序/初中.jsonl` 与 `高中.jsonl`：
  1. 逐行 JSON 解析，**跨两库**按 `wordHead` 分组；
  2. 同一单词的所有来源行**合并**：释义取并集（按 pos+tran 去重）、例句取并集（按 en 去重）、短语取并集（按 en 去重），音标取任一非空值；
  3. 学段推导：该词出现在任一初中词书（`ChuZhong_*`）→ 「初中」，否则 → 「高中」；
  4. 写入 `e_words`（幂等：清空后重插，或按 word 冲突跳过——实现时取简单可靠者）；
  5. 输出导入统计日志到 `logs/`（每库行数、去重数、学段分布）。
- 启停脚本：新增 `scripts/import-english.sh`；`scripts/setup.sh` 增加 submodule 初始化步骤。

## 七、题型与出题规则

**题型**（对应现有 ReviewMode）：
- `choice` 英译中：展示单词（+音标），4 个中文释义选项，正确项取该词第一条释义的 `tran`，干扰项从其他单词释义中随机取 3 个（去重、不含正确答案）；
- `fill` 中译英：展示全部释义（多条拼接），输入框拼写单词；判定**大小写不敏感、去首尾空白**后精确匹配。

**作答结果**保留三态：correct / wrong / unknown（「不认识」）。

**出题规则**（英语模块第一期的 QuizRule）：
- `random` 随机
- `level` 按学段（value = 「初中」|「高中」）
- `initial` 按首字母（A-Z）
- `weakness` 弱项优先（照现有 weakness 模式：按 e_review_logs 错误率排序，未作答过的词补足）

> 文言文的 `keyword`（按字查）与 `frequency`（词频）不适用英语场景，第一期不做；`frequency` 因去重合并后 wordRank 失去意义。

## 八、统计

照 `stats.ts` 模式另立 `e-stats`：
- 总体汇总（correct/wrong/unknown、正确率、错误率、未复习数）
- 按学段聚合（初中 / 高中）
- 按首字母聚合
- 近 7 天趋势

## 九、API（复用现有路由模式）

| 路由 | 功能 |
|---|---|
| `GET /api/english/quiz?rule=&value=&count=&mode=` | 出题（与现有 /api/quiz 同参数模式） |
| `POST /api/english/review` | 记录一次作答（填空传 input 由服务端判定；支持「判我对」覆盖） |
| `GET /api/english/stats` | 统计汇总/维度/趋势 |

## 十、页面

- `/english/review`：选择出题规则 → 复习会话（选择题卡片 / 拼写卡片）→ 会话小结；
- `/english/stats`：统计卡片 + 按首字母正确率 + 趋势图；
- 首页与顶部导航：加「文言文 / 英语单词」切换入口。

## 十一、非目标（第一期不做）

- 英语管理页（词条列表/编辑/手动添加）
- 其他学段词库（四级/考研等）——表结构与导入流程已按词库文件参数化，后续加数据文件即可
- 单词发音播放（usspeech 依赖外部 API）
- 同近义词/同根词的展示与出题（数据保留在 meanings 之外的导入中暂不存储，第一期用不到）

## 十二、留给实现阶段的事项

- 导入幂等策略取「清空重插」还是「按 word 跳过」，实现时定；
- 会话组件（ReviewSession 等）与文言文版相似度高，实现时评估是抽公共组件还是复制组件——倾向**先复制后重构**，避免为复用而过早抽象；
- 测试照现有 `__tests__` 模式补齐（导入去重、出题、判定、统计）。
