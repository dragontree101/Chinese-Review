# 文言文统计页「点击字 → 详情弹窗」实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 文言文统计页「按字排行」的每一行可点击，弹窗展示该字下全部词条的详情（读音、含义、例句、白话翻译）。

**Architecture:** 仿照英语模块 `EnglishStatTables` + `EnglishWordDetailDialog` 的既有模式：新增按字精确查询 API → 新建 `CharDetailDialog` 组件 → `StatTables` 的按字表接入可点击行并挂载弹窗。统计页 `page.tsx` 不动（弹窗状态收敛在 `StatTables` 内，与英语模块一致）。

**Tech Stack:** Next.js 15.4 Route Handlers、React 19、TypeScript strict、Tailwind CSS v4、vitest

**Spec:** 会话内已确认的短设计（2026-11-28）；参照实现：`src/components/english/EnglishStatTables.tsx`、`src/components/english/EnglishWordDetailDialog.tsx`、`src/app/api/english/words/[word]/route.ts`

## Global Constraints

- TypeScript strict 模式，禁用 `any`（本项目禁 commonjs、强类型优先）
- 所有运行/测试一律通过 `scripts/` 下的 .sh 脚本（如 `bash scripts/test.sh`），不直接调 npm/vitest
- UI 文案使用简体中文
- 查询必须**精确等值匹配 char**，不得复用 `/api/words?q=` 的 LIKE 模糊搜索（会把含义/例句中含该字的词条误带出来）
- 弹窗必须展示该字下**全部**词条（一个多义字对应多条词条），不得只取第一条
- 不改统计口径、不加删除/编辑能力

## Review Focus

1. **模糊匹配误伤**：`char=哀` 只返回 `char === '哀'` 的词条，含义或例句里含「哀」的其他字（如「哀兵必胜」成语条目的 char 为其他字）不得出现 → Task 1 测试断言精确等值。
2. **多义字多条词条**：同一个字有 3+ 条含义词条时，弹窗逐条全部展示 → Task 1 测试断言返回数组长度、Task 2 渲染逐条卡片。
3. **读音去重**：手动添加的词条 `keyword` 缺省等于 `char`，此时读音行不得重复显示同一个字 → Task 2 渲染时 `keyword !== char` 才显示。
4. **空结果**：传入的字查不到任何词条（数据被人工修正后字符变更的极端情况）时，弹窗显示「未找到词条」而非空白或报错 → Task 2 渲染空态。

### Task 2: CharDetailDialog 弹窗组件

**Files:**
- Create: `src/components/CharDetailDialog.tsx`

**Interfaces:**
- Consumes: `GET /api/words?char={char}`（Task 1）、`Word` 类型（`@/lib/types`）
- Produces: `CharDetailDialog({ char, onClose }: { char: string; onClose: () => void })`（默认导出；Task 3 挂载）

- [ ] **Step 1: 实现组件**

整体结构照抄 `EnglishWordDetailDialog.tsx`（遮罩点击关闭、`stopPropagation`、加载中/错误/关闭按钮、`useEffect` 按 `char` 拉取）。差异点：

- 拉取 `GET /api/words?char=${encodeURIComponent(char)}`，响应为 `{ items: Word[] }`
- 头部：大号显示 `char`；若词条带读音（`keyword` 形如 `辟(bì)` 或不等于 `char`），在字旁小字展示
- 空数组渲染 `<p>未找到词条</p>`（Review Focus 第 4 条）
- `items` 逐条渲染卡片（`border-t` 分隔），每条包含：含义（加粗）、例句原文（句末括号出处保留）、白话翻译（灰色小字，有才显示）、`课文 / 年级 / 出处` 标签（有才显示，样式仿英语弹窗的 `level` 徽标）
