# SRS 间隔重复 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 文言文与英语两个模块引入固定阶梯式间隔重复：状态从作答日志实时推导，新增「智能复习」出题规则（置顶默认）、作答后的 SRS 轻提示、会话小结的升级/归零/毕业统计、统计页掌握度分桶。

**Architecture:** 新建共享 `src/lib/srs.ts`（重放推导 + 到期选题，两模块以表名参数复用，**不新增调度表**）；两条 quiz 路由加 `due` 规则；两条 review 路由响应携带 SRS 状态；新增 `GET /api/srs/progress`（两模块各一份）供设置页与统计页使用。UI 层：设置单置顶智能复习、答题卡轻提示、小结与统计页分桶。

**Tech Stack:** Next.js 15.4、React 19、TypeScript strict、better-sqlite3、vitest

**Spec:** [discuss/2026-11-28-间隔重复-design.md](2026-11-28-间隔重复-design.md)（已评审批准，含三条裁决：固定阶梯、两模块、到期全出+自主加练；答错次日到期、英语不分学段、review 响应返回 SRS 状态、毕业无粘性）

## Global Constraints

- **不改表结构、不改 review_logs 写入逻辑**（SRS 只读日志）；不改现有 6+4 种出题规则的行为。
- 阶梯与间隔：level 0..6，`SRS_INTERVALS = [1, 1, 2, 4, 7, 15]`（索引=level，单位天），level 6 = 毕业；答对升级 `min(level+1, 6)`，答错/不知道归零。
- **到期时刻按本地自然日**：`dueAt = 最后一次作答的本地日 + 间隔天数` 的当天 00:00（本地时区）ISO 串；答错归零走 `SRS_INTERVALS[0]=1`，即次日到期。
- due 选题：到期词（`dueAt <= now` 且未毕业）按 `dueAt` 升序（最久未到期优先）全出，封顶 30；新词（无日志）随机补齐至总数 ≥ 10；**不引入未到期词**；英语模块新词补齐不分学段。
- 时间比较一律用 ISO 串（`toISOString()` 均为 UTC 等长格式，字典序即时间序）；日界运算用本地时区。
- TypeScript strict、禁 any；运行/测试走 `scripts/*.sh`；UI 文案简体中文；每个文件 ≤ 800 行。
- 现有统计（summary/byChar/byGrade/bySource/byWord/trend）口径不动。

## Review Focus

1. **「判我对」计入重放**：覆盖后的记录 `result='correct'`，重放必须按 correct 升级 → 测试断言。
2. **跨自然日到期**：6 月 1 日 21:30 答对 → 6 月 2 日 00:00 起到期（本地时区）→ 测试断言 dueAt 精确值。
3. **不引入未到期词**：昨天答对（间隔未满）的词不得出现在 due 队列 → 测试断言。
4. **答错的词次日才到期**：今天答错的词 dueAt 是明天，当下不再重出 → 测试断言。
5. **毕业封顶**：连对至 level 6 后 graduated=true、dueAt=null、不再进 due 队列 → 测试断言。
6. **「判我对」响应替换不双计**：会话小结的升级/归零/毕业计数以每题最新一次响应为准，判我对后替换该题原有变化量（UI 层，手动验收）。

```ts
export const SRS_GRADUATED = 6;
export const SRS_INTERVALS = [1, 1, 2, 4, 7, 15]; // 索引=level，天
export interface SrsState {
  level: number;      // 0..6
  graduated: boolean; // level === 6
  /** 毕业或从未作答为 null；否则为本地日 00:00 的 ISO 串 */
  dueAt: string | null;
  isNew: boolean;     // 无日志
}
/** 重放单个词条的日志推导状态（logs 内部按 createdAt 升序排序后重放） */
export function computeSrsState(
  logs: Array<{ result: "correct" | "wrong" | "unknown"; createdAt: string }>,
  now?: Date,
): SrsState;
/** 全库状态：wordId → SrsState（表名仅允许 'review_logs' | 'e_review_logs'，防注入） */
export function getAllSrsStates(
  db: Database, logsTable: "review_logs" | "e_review_logs",
): Map<number, SrsState>;
/** 单词条状态（review 路由响应用） */
export function getSrsStateForWord(
  db: Database, logsTable: "review_logs" | "e_review_logs", wordId: number,
): SrsState;
/** due 选题：到期(封顶 cap)→新词补齐(至 minBatch)；返回 ids 与元信息 */
export function pickDueWords(
  db: Database,
  wordsTable: "words" | "e_words",
  logsTable: "review_logs" | "e_review_logs",
  opts?: { cap?: number; minBatch?: number; now?: Date },
): { ids: number[]; dueCount: number; newCount: number };
/** 掌握度分桶 + 到期/新词计数（设置页与统计页共用） */
export function getSrsProgress(
  db: Database,
  wordsTable: "words" | "e_words",
  logsTable: "review_logs" | "e_review_logs",
  now?: Date,
): {
  unlearned: number; learning: number; graduated: number;
  byLevel: number[]; // 长 7，索引=level（毕业计入 [6]）
  dueCount: number;
};
```
